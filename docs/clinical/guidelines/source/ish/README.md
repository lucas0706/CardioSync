# Referencia internacional: ISH Global Hypertension Practice Guidelines 2020

## Estado en CardioSync

**Estado:** referencia bibliográfica para comparación; extracción documental y evaluación de vigencia pendientes.

En el código auditado no se identificó un motor ISH ni un conjunto de objetivos terapéuticos asociados a un identificador ISH. La guía argentina es la predeterminada del servicio de análisis y el repositorio de objetivos únicamente devuelve datos para `consenso-hta-argentina-2025`.

## Condiciones para utilizar esta fuente

Antes de usar ISH para justificar una regla:

- verificar la publicación oficial y si fue sustituida o actualizada;
- registrar URL o identificador persistente y fecha de consulta;
- identificar sección y página exactas;
- describir población y ámbito de medición;
- documentar qué recomendación se compara y si se implementará;
- evitar mezclar umbrales ISH con los de otras guías en una regla única sin una decisión explícita.

La referencia se conserva como contexto documental; no debe interpretarse como funcionalidad clínica disponible.
