# Guideline Extraction

Esta carpeta contiene extracciones estructuradas desde las fuentes clínicas.

Cada extracción debe conservar:

- documento fuente;
- versión;
- fecha;
- página/sección;
- texto extraído;
- decisión arquitectónica asociada.

Formato recomendado:

1. Fuente
2. Ubicación
3. Hallazgo clínico
4. Impacto en CardioSync
5. Decisión derivada

No se incorporan reglas clínicas sin trazabilidad.
